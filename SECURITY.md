# Security

Please report security problems privately via GitHub's "Report a vulnerability" (Security tab) instead of a public issue.

**Never paste a Discord token or a webhook URL into an issue.** Anyone who has a webhook URL can post into that channel. If you leaked one, delete it in Discord (Channel settings → Integrations → Webhooks) or with the [webhook manager](https://discordtools.de/webhook-manager).

discordtools.de has no backend: every tool runs in your browser, and requests to Discord go straight from your browser to Discord.
